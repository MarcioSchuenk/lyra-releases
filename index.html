Funcionalidades

Privacidade sem abrir mão
do conforto

Tudo que você precisa para guardar arquivos sensíveis com segurança, sem depender de serviços externos nem abrir mão de uma boa experiência.

🔐

Criptografia forte

AES-256-GCM com chave derivada via PBKDF2-SHA256. Cada arquivo tem seu próprio nonce e tag de autenticação — sem brechas.

📴

100% offline

Nenhum byte sai do seu aparelho. Sem conta, sem nuvem, sem servidor. Só você e sua senha.

🚨

Senha de pânico

Configure uma segunda senha: quem digitar ela vê o app desbloquear — mas o cofre inteiro é apagado imediatamente.

🧮

Ícone disfarçado

O app pode aparecer como "Calculadora" na sua gaveta de apps. Ninguém precisa saber que ele existe.

💾

Backup da chave

Exporte o sal e o número de iterações para recuperar o cofre em um novo aparelho com a mesma senha mestra.

🖼

Álbuns e busca

Visualize arquivos agrupados por pasta, busque por nome e organize do jeito que você prefere.

🗑

Lixeira de 30 dias

Arquivos apagados vão para a lixeira antes de sumir. Restaure o que precisar; o restante é destruído automaticamente.

📤

Criptografar da galeria

Compartilhe fotos e vídeos direto da galeria do Android para o LYRA — eles entram criptografados sem passar por apps de terceiros.

⏱

Bloqueio automático

O cofre se tranca sozinho depois que o app vai para o segundo plano. Você define o tempo — ou desativa se preferir.

Como funciona

Simples por fora,
sólido por dentro

Escolha a senha mestra

No primeiro uso você define uma senha. O LYRA deriva uma chave criptográfica dela — a senha em si nunca fica salva.

Adicione arquivos

Mova fotos, vídeos ou documentos do armazenamento para o cofre — ou compartilhe direto da galeria.

Acesse quando precisar

Desbloqueie com a senha, veja e reproduza seus arquivos normalmente. O app trava sozinho quando você sai.

Seus arquivos ficam no seu aparelho

Nenhum servidor processa seus dados. Faça backup da chave para um pendrive e migre para qualquer dispositivo.

Criptografia

Auditável.
Sem truques.

O formato .lyra usa apenas primitivos criptográficos consolidados, implementados em Java puro sem dependências externas. Cada detalhe é inspecionável no código.

AES-256-GCM Cifra autenticada — detecta qualquer adulteração no arquivo
PBKDF2-SHA256 · 200 000 iterações Derivação custosa de chave — torna ataques de força bruta inviáveis
Nonce único por arquivo Nunca reutilizado; gerado pelo SecureRandom do sistema
fsync + verificação de SHA O original só é apagado após confirmar que o .lyra está íntegro no disco
// formato .lyra v1
magic LYRA // 4 bytes
version 01 // 1 byte
nonce ··· // 12 bytes (GCM IV)
salt ··· // 16 bytes
iter 200 000 // 4 bytes
tag ··· // 16 bytes (autenticação)
payload ··· // dados cifrados

// chave = PBKDF2(senha, salt, iter)
// AES/GCM/NoPadding · 256 bits
